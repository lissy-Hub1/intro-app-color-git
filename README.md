> Aplicación desarollada por  [Lisset Guriérrez Cruz](https://www.linkedin.com/in/lisset-guti%C3%A9rrez-cruz-65a439349/)

Bienvenido a **intro-app-color-git**, una aplicación moderna y sencilla que permite seleccionar colores de una manera visualmente atractiva y funcional. Esta aplicación está construida utilizando **HTML** y **Bootstrap** para ofrecer un diseño limpio y atractivo. Ideal para desarrolladores y diseñadores que buscan integrar selectores de color de forma rápida y eficiente en sus proyectos.

## Características

- **Selector de colores interactivo**: El usuario puede elegir colores mediante una interfaz visual.
- **Diseño moderno y elegante**: Utiliza Bootstrap para asegurar un diseño atractivo y adaptable a cualquier dispositivo.
- **Colores predefinidos y personalización**: Permite seleccionar colores específicos y obtener su código hexadecimal.
- **Responsive**: Funciona perfectamente en dispositivos móviles, tabletas y escritorios.

## Tecnologías utilizadas

- **HTML5**: Para la estructura básica de la app.
- **Bootstrap 4**: Para el diseño responsivo y la creación de componentes interactivos.
- **CSS**: Para personalizar el estilo y mejorar la experiencia visual.
